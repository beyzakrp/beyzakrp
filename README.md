# Beyza Karapıçak

### Product-minded developer · Design & engineering

I build web products by connecting engineering, interface design and hands-on entrepreneurship. My background is in astronautical engineering at ITU; my projects have taught me to take an idea through design, development and the way it is presented to users.

Through my ventures, I have worked across UI/UX, software development, video and content production, and social media. I learn the tools a problem needs, build a working version, and keep improving it.

## Selected work

### Calc Marine — engineering workflows on the web
A web application for shipbuilding and ship manoeuvring calculations, including turning-circle, crash-stop, zigzag and Williamson-turn workflows. It brings calculations, saved results and Turkish/English interfaces into one product.

**Built with:** Next.js, React, Tailwind CSS and Firebase.  
[Product website](https://www.calcmarine.com) · Source code is private.

### Fourtune — brand experience in code
A multilingual agency website that connects brand identity with responsive interface design and interaction. The implementation includes four locales, reusable motion primitives and reduced-motion support.

**Built with:** Next.js, TypeScript, React, Tailwind CSS and Motion.  
[Visit the website](https://fourtuneagency.com) · [Explore the repository](https://github.com/beyzakrp/fourtune-wesite-next)

*In development: the current version includes placeholder content; contact email delivery is not yet connected.*

### Renart — product discovery case study
A jewelry catalog interface with product variants, price and popularity filters, a carousel, and API-based gold pricing.

**Built with:** Next.js, TypeScript and Tailwind CSS.  
[Explore the repository](https://github.com/beyzakrp/renart-case-study)

### Seagull Trading — service website
A responsive, animated service website with a static deployment workflow and a PHP contact relay. The current scope is a marketing website with a QR-menu demo.

**Built with:** Next.js, React, TypeScript, Tailwind CSS and Motion.  
[Visit the website](https://seagulltrading.me) · [Explore the repository](https://github.com/beyzakrp/seagull-trading-source)

## How I work

- **Start with the user:** turn a practical need into a clear flow and interface.
- **Build across disciplines:** connect product thinking, design and implementation.
- **Learn by shipping:** use small iterations to turn unfamiliar problems into working software.
- **Make the product understandable:** bring content, video and visual communication into the work.
